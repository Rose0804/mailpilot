# 安全与审批

## 1. 不可信内容

邮件正文、HTML、附件文本、OCR 结果和外部网页都属于不可信数据。它们可以作为事实来源，但不能改变 Agent 的系统规则、工具权限或审批要求。

## 2. 风险分级

| 等级 | 示例 | 默认行为 |
| --- | --- | --- |
| 低 | 搜索、读取、摘要、预览 | 自动执行 |
| 中 | 创建草稿、标记已读、单封归档 | 可配置，默认自动执行 |
| 高 | 发送、回复、批量移动 | 必须确认 |
| 极高 | 删除邮件、修改账号权限、上传敏感文件 | 二次确认或禁止 |

## 3. 多账号规则

- 回复默认使用原邮件所属账号。
- 新建邮件遇到多个账号时必须明确选择。
- 同名联系人不能作为账号路由依据。
- 所有结果必须展示来源账号。
- 账号切换不能改变已有审批请求的目标账号。

## 4. 凭据

凭据存储在 macOS Keychain。配置文件只保存账号标识和非敏感连接参数。
