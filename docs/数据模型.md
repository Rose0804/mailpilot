# 数据模型

## 1. 账号标识

```ts
type AccountRef = {
  provider: "apple-mail" | "gmail" | "imap" | "exchange";
  accountId: string;
  email: string;
  displayName: string;
};
```

任何邮件操作都必须携带账号信息，不能只使用一个可能冲突的数字消息 ID。

## 2. 邮件标识

```ts
type MessageRef = {
  account: AccountRef;
  mailboxId: string;
  messageId: string;
  internetMessageId?: string;
  threadId?: string;
};
```

## 3. 附件

```ts
type Attachment = {
  id: string;
  message: MessageRef;
  filename: string;
  mimeType: string;
  size: number;
  contentHash?: string;
  localPath?: string;
  extractedTextPath?: string;
  previewPath?: string;
  indexStatus: "pending" | "ready" | "failed";
};
```

## 4. 核心数据表

| 数据表 | 用途 |
| --- | --- |
| `accounts` | 邮箱账号、提供商和显示信息 |
| `mailboxes` | 收件箱、已发送、草稿和本地邮箱 |
| `messages` | 邮件头、正文、同步状态 |
| `threads` | 会话聚合和排序 |
| `attachments` | 附件元数据和解析状态 |
| `attachment_chunks` | 附件文本分块和全文索引 |
| `sync_cursors` | 每个账号和邮箱的同步游标 |
| `agent_runs` | Agent 任务运行记录 |
| `agent_steps` | 可审计的工具调用步骤 |
| `approval_requests` | 等待用户确认的写操作 |
| `audit_events` | 关键状态变更记录 |

`attachments` 保存附件元数据和本地核心路径，`attachment_search` 保存解析文本分块。`local_path`、`extracted_text_path` 和 `preview_path` 永远不直接返回给 Agent；Agent 通过 `mailpilot://attachment/<account-id>/<attachment-id>/text` 或 `.../preview` 访问受控资源。

## 5. 数据保留

- 原始附件由用户主动下载或索引时保存。
- 可重建的缓存允许清理。
- 审批和审计记录默认保留。
- 日志中不得写入完整正文、附件内容或凭据。
