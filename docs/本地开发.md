# 本地开发

## 环境要求

- macOS
- Node.js 22 或更高版本
- pnpm 10
- Rust stable（通过 rustup 安装）

如果当前终端还没有加载 Rust 环境，执行：

```bash
source "$HOME/.cargo/env"
```

当前已验证的工具链：

```text
rustc 1.98.1
cargo 1.98.1
tauri-cli 2.11.4
aarch64-apple-darwin
```

## 启动桌面端原型

```bash
pnpm install
pnpm --filter @mailpilot/desktop dev
```

当前原型使用浏览器窗口模拟桌面工作台。后续接入 Tauri 后，React 页面将复用为 Tauri WebView 内容。

Tauri 原生壳准备就绪后，可使用：

```bash
pnpm tauri info
pnpm tauri dev
```

## 检查

```bash
pnpm -r lint
pnpm -r test
pnpm --filter @mailpilot/desktop build
```

## 当前测试范围

- 示例邮件是否绑定到有效账号。
- 搜索是否能找到指定主题。
- 邮件引用是否拒绝缺少账号、邮箱、邮箱文件夹或消息标识的请求。
- 发送和删除是否被标记为需要审批的高风险操作。
