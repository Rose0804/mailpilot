# 本地开发

## 环境要求

- macOS
- Node.js 22.19.0 或更高版本
- pnpm 10
- Rust stable（通过 rustup 安装）

如果当前终端还没有加载 Rust 环境，执行：

```bash
source "$HOME/.cargo/env"
```

当前已验证的工具链：

```text
rustc 1.98.1
cargo 1.98.1
tauri-cli 2.11.4
aarch64-apple-darwin
```

## 启动桌面端原型

```bash
pnpm install
pnpm --filter @mailpilot/desktop dev
```

浏览器模式只启动 Vite：

Tauri 原生壳准备就绪后，可使用：

```bash
pnpm tauri info
pnpm tauri:dev
```

`pnpm tauri:dev` 会通过 `scripts/dev-local.sh` 同时启动 Vite 和本地 API。Tauri WebView 只访问本地 API，不直接调用 Mail.app。

真实链路：

```text
Tauri WebView
  -> http://127.0.0.1:3100
  -> MailPilotLocalApi
  -> SQLite/FTS5
  -> Apple Mail Connector（点击同步时）
```

浏览器模式下也可以直接打开 `http://localhost:5173`。如果本地 API 尚未启动，页面会显示演示数据；如果 API 已启动但索引为空，页面会显示空索引状态，不会伪造邮件。

## 真实 Apple Mail 只读链路

同步本机 Mail.app 的账号、文件夹和邮件：

```bash
pnpm --filter @mailpilot/sync sync
```

启动 MCP Server：

```bash
pnpm --filter @mailpilot/mcp-server exec tsx src/cli.ts
```

默认数据库位置是 `~/Library/Application Support/MailPilot/mailpilot.sqlite`。开发或测试时可用 `MAILPILOT_DB_PATH` 指定其他路径。

本地 API 的主要接口：

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/health` | 检查本地 API 是否存活 |
| GET | `/api/snapshot?query=...` | 返回账号、邮箱和邮件列表 |
| GET | `/api/messages/<account>/<mailbox>/<message>` | 返回邮件正文和附件元数据 |
| GET | `/api/attachments/<account>/<attachment>/text` | 返回附件解析文本 |
| POST | `/api/sync` | 从 Apple Mail 同步账号、邮箱和邮件 |
| POST | `/api/agent/sessions` | 创建 Agent 会话 |
| GET | `/api/agent/sessions/<session>` | 获取 Session 元数据 |
| GET | `/api/agent/sessions/<session>/events` | 获取可审计事件历史 |
| POST | `/api/agent/sessions/<session>/messages` | 发送消息并返回结构化事件 |
| POST | `/api/agent/sessions/<session>/steer` | 向当前运行中的 Agent 注入指导 |
| POST | `/api/agent/sessions/<session>/follow-up` | 排队下一轮 Agent 消息 |
| POST | `/api/agent/sessions/<session>/abort` | 中止当前 Agent 运行 |

## Agent Runtime 配置

默认启动 Pi Agent Runtime：

```bash
export DEEPSEEK_API_KEY="..."
export MAILPILOT_AGENT_RUNTIME=pi
export MAILPILOT_PI_MODEL=deepseek-v4-flash
pnpm --filter @mailpilot/local-api dev
```

Pi 会把 Session 元数据和可审计事件写入：

```text
<数据库目录>/agent-sessions/
```

默认 Pi 工具包括 `list_accounts`、`list_mailboxes`、`search_messages`、`get_message`、`search_attachments`、`get_attachment_metadata` 和 `get_attachment_text`。这些工具直接使用 MailPilot 的本地查询服务，并按 Session 的 `accountIds` 强制账号隔离。

## DSH 兼容配置

官方 DSH SDK 运行时需要显式 `DSH_HOME`。配置 DSH 后，启动本地 API：

```bash
export MAILPILOT_AGENT_RUNTIME=dsh
export MAILPILOT_DSH_COMMAND=dsh
export MAILPILOT_DSH_HOME="$HOME/Library/Application Support/MailPilot/dsh-home"
export DSH_HOME="$MAILPILOT_DSH_HOME"
pnpm --filter @mailpilot/local-api dev
```

API 会生成 `dsh-mcp-mailpilot.patch.yml`，通过 `@deepseek-ai/dsh-mcp-client` 挂载 MailPilot MCP。也可以用 `MAILPILOT_DSH_ARGS` 自定义 `dsh` 参数，但要保留 SDK JSON-RPC profile。DSH 只作为兼容运行时，不是 MailPilot 的默认 Agent Loop。

## 当前测试范围

- 示例邮件是否绑定到有效账号。
- 搜索是否能找到指定主题。
- 空索引不会回退为示例邮件。
- 附件文本预览不会返回附件绝对路径。
- 邮件引用是否拒绝缺少账号、邮箱、邮箱文件夹或消息标识的请求。
- 发送和删除是否被标记为需要审批的高风险操作。
